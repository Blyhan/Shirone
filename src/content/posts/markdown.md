# 一级标题

段落之间用空行分隔。

第二段。_斜体_、**粗体** 与 `等宽字体`。项目符号列表
看起来像这样：

- 这个
- 那个
- 另一个

请注意——先不考虑星号——实际的文本
内容都是从第 4 列开始的。

> 块引用是
> 这样书写的。
>
> 如果你愿意，它们也可以
> 跨多个段落。

用 3 个连字符表示长破折号，用 2 个连字符表示范围（例如“全部内容
都在第 12--14 章”）。三个点 ... 会转换为省略号。
支持 Unicode。☺

## 二级标题

这是一个有序列表：

1. 第一项
2. 第二项
3. 第三项

请注意，实际文本依然从第 4 列开始（即距左侧 4 个字符）。
下面是一个代码示例：

    # 让我再重复一遍……
    for i in 1 .. 10 { do-something(i) }

你大概已经猜到了，缩进 4 个空格即可。顺便说一句，除了
缩进这个块之外，你也可以使用分隔块：

```
define foobar() {
    print "Welcome to flavor country!";
}
```

（这样复制粘贴更方便）。你也可以选择为这个
分隔块加上 Pandoc 的语法高亮标记：

```python
import time
# 快，数到十！
for i in range(10):
    # （但也别 *太快*）
    time.sleep(0.5)
    print i
```

### 三级标题

现在来看一个嵌套列表：

1. 首先，准备这些食材：

    - 胡萝卜
    - 芹菜
    - 小扁豆

2. 烧一些水。

3. 把所有东西倒进锅里，然后按照
    这个算法操作：

        find wooden spoon
        uncover pot
        stir
        cover pot
        balance wooden spoon precariously on pot handle
        wait 10 minutes
        goto first step (or shut off burner when done)

    不要碰木勺，否则它会掉下来。

请注意，文本始终按 4 空格缩进对齐（包括
上面延续第 3 项的最后一行）。

这里有一个指向[某个网站](http://foo.bar)的链接，一个指向[本地
文档](local-doc.html)的链接，以及一个指向[当前
文档中的章节标题](#an-h2-header)的链接。这里还有一个脚注 [^1]。

[^1]: 脚注文本写在这里。

表格看起来可以是这样：

多行表格：

红色 日落、苹果，以及
其他红色或偏红的
事物。

绿色 叶子、草地、青蛙，
以及其他难以
长期保持一致的事物。

再次说明，文本缩进 4 个空格。（在每个
术语/定义对之间空一行，可以让内容更舒展。）
